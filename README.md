# MINN — Google Colab Miner

Mining Kryptex Pearl (PRL) + Tidecoin (TDC) di Google Colab.

## Cara Pake

### 1. `oneliner.sh` — 1 baris, langsung jalan
Copy-paste isi file ke terminal Colab:
```bash
bash <(curl -s https://raw.githubusercontent.com/brandalgenius/minn/master/oneliner.sh)
```

### 2. `run.sh` — Versi lengkap dgn auto-shutdown 4 jam
```
bash <(curl -s https://raw.githubusercontent.com/brandalgenius/minn/master/run.sh)
```

### 3. `run.py` — Python obfuscated (paling aman)
Copy-paste ke cell Colab:
```
!wget -q https://raw.githubusercontent.com/brandalgenius/minn/master/run.py -O run.py && python3 run.py
```
